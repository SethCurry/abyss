This is a glossary of terms spawned because even I have trouble keeping track of terms within Abyss.

## Glossary

| Term | Definition |
| ---- | ---------- |
| Client Proxy | The Abyss component that runs on the host PC and accepts stdio connections from the ACP client. |
| Agent Proxy | The Abyss component that runs inside the container and speaks stdio to the underlying agent. |
